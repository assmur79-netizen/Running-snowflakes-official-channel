# 🎄 GameHub

Новогодний игровой сайт: регистрация по почте, бесплатная рулетка раз в день, кейсы, внутриигровая валюта (монеты и снежки), пасс, промокоды и панель разработчика с банами и техническими работами.

## Возможности

**Для игроков**
- Регистрация только по почте. Выдаётся личный ключ для входа с другого устройства.
- 🎡 Бесплатная рулетка: 1 прокрутка в день (2 с пассом).
- 🎁 Кейсы за монеты: Снежок, Подарок, Ёлка, Дед Мороз.
- ❄️ Снежки (жёлтая монета «С»): выпадают из кейсов с шансом 3%, чем больше награда — тем реже. Можно обменять на монеты по курсу 100 🪙 = 1 С.
- 🎟 Пасс за снежки: ежедневный подарок монетами и вторая прокрутка рулетки.
- Промокоды на монеты и снежки.
- Новости на главной странице.

**Для разработчика** (Настройки → «Режим разработчика» → код доступа)
- Баны по почте с причиной и сроком, разбан.
- Выдача и снятие монет и снежков.
- Промокоды: свой или случайный код, срок действия (дни/часы/минуты), лимит активаций, заметка, включение/выключение.
- Закрытие отдельных кейсов, изменение цен.
- Настройка пасса (цена, срок, подарок в день) и курса снежков.
- Режим технических работ: сайт закрыт для всех, кроме разработчика.
- Публикация новостей и смена кода доступа.

## Файлы

| Файл | Что это |
|---|---|
| `GameHub.html` | Весь сайт одним файлом. Открывается прямо в браузере, данные хранятся на устройстве (localStorage) |
| `server.js` | Сервер на Node.js (18+), без зависимостей |
| `server.py` | Тот же сервер на Python 3.6+, без зависимостей |
| `index.html`, `app.js`, `style.css` | Страницы сайта для серверных версий |
| `config.json` | Хэш кода разработчика |
| `standalone/` | Сборка `GameHub.html` из исходников |

## Запуск

### Вариант 1. Один файл, без сервера
Откройте `GameHub.html` в браузере.

Все данные лежат в браузере одного устройства: другие игроки вас не увидят, а при очистке данных браузера всё пропадёт. Подходит для просмотра и проверки.

### Вариант 2. Сервер на Node.js
```bash
node server.js
```
Откройте <http://localhost:3000>.

### Вариант 3. Сервер на Python
```bash
python server.py
```
Откройте <http://localhost:3000>. Запускается и в Pydroid 3 на Android.

### Настройки сервера (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт |
| `HOST` | `0.0.0.0` | Адрес |
| `TZ_OFFSET_HOURS` | `5` | Часовой пояс, по нему определяется «новый день» для рулетки |
| `TRUST_PROXY` | выключено | `1`, если сайт стоит за nginx или Cloudflare |

Игроки и промокоды сохраняются в файле `data.json` рядом с сервером.

## Код разработчика

Код **не хранится в репозитории**, в `config.json` лежит только его хэш. Если вы клонировали проект и не знаете код, создайте свой.

Для `server.js` и `server.py`:
```bash
node -e "const c=require('crypto');const pw=c.randomBytes(18).toString('base64url');const salt=c.randomBytes(16).toString('hex');require('fs').writeFileSync('config.json',JSON.stringify({devSalt:salt,devHash:c.scryptSync(pw,salt,64).toString('hex')},null,2));console.log('Ваш код:',pw)"
```
Для `GameHub.html` пересоберите файл со своим кодом:
```bash
node standalone/build.js "ВАШ_КОД"
```
Код можно сменить и из самого сайта: Админка → «Код доступа».

## Безопасность

- Код разработчика проверяется на сервере (scrypt), после 8 неверных попыток вход блокируется на 15 минут, сессия разработчика живёт 2 часа.
- Запросы с чужих сайтов отклоняются, куки `HttpOnly` и `SameSite=Strict`.
- Призы рулетки и кейсов выбираются на сервере.
- Перед публикацией в интернет поставьте сайт за HTTPS и запускайте с `TRUST_PROXY=1`.
- В режиме `GameHub.html` проверка кода выполняется прямо в файле, поэтому он не защищён от человека, который разбирается в коде. Для настоящих игроков используйте сервер.
- Не публикуйте в репозитории `data.json`: там почты игроков.
